# Preguntas abiertas

Lo que ninguna regla define todavía. Solo Carlos las puede contestar. Cada respuesta se anota
en [decisions.md](decisions.md) y en el capítulo que toca, y la pregunta se borra de acá.

Se agregan a medida que se escribe cada capítulo. Las de los capítulos que todavía no se
escribieron siguen en `ferre`
([specs/preguntas-abiertas.md](https://github.com/carlos-illobre/ferre/blob/master/specs/preguntas-abiertas.md));
el analista de negocio las retoma cuando le toca a su módulo.
